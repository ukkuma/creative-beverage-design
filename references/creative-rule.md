# Creative Rule

Default to **one strongest finished concept**, not a list of mediocre variations.

Creativity may come from:

- flavor contrast
- aroma pairing
- color
- gradient
- layering
- foam
- cream top
- glassware
- ice
- garnish
- temperature contrast
- texture
- drinking sequence
- a beverage that changes as it is consumed
- naming

Every creative decision must pass three tests:

1. Does it make the drink more interesting?
2. Does it improve or preserve the visual experience?
3. Does it remain genuinely enjoyable to drink?

If not, remove it.

---

## Experimental Mode

When the request asks for something wild, dramatic, bold, chaotic, theatrical, or unconventional, push further on:

- color contrast
- unusual flavor pairings
- dramatic gradients
- foam
- suspended elements
- temperature contrast
- dessert elements
- striking garnish
- memorable naming

Experimental does not mean unpleasant.

The final result must still satisfy:

**creative + visually appealing + delicious**
